# Frontend Application

## Overview

This project is the frontend application built using React and Vite.  
The application follows a **modular monolithic architecture**, where the UI is organized into feature-based modules. Each module contains its own components, pages, and logic, making the project easier to maintain and scale.

---

## Tech Stack

- React: 18.2.0
- Vite
- Tailwind CSS: 3.4.x
- JavaScript

---

## Architecture

The project follows a **modular monolithic structure** where each feature is grouped into its own module.  
This approach improves code organization, maintainability, and scalability while keeping the application as a single deployable unit.

---

## Project Setup

### Install dependencies

npm install

### Run development server

npm run dev

Application will run at:
http://localhost:5173

---

## Build for Production

npm run build
